# ☕ Starbucks Brewing Insights & Nutritional Analysis (Power BI Dashboard)

An interactive Power BI dashboard designed to analyze Starbucks beverages, their nutritional values (Calories, Sugar, Caffeine), and global presence[cite: 1].

---

## 📊 Dashboard Overview
This dashboard provides deep insights into Starbucks beverages with a clean and modern aesthetic matching the brand's theme[cite: 1].

### 🌟 Key Metrics (KPIs):
* **Total Beverages:** 33 analyzed items[cite: 1].
* **Average Sugar:** 193.78[cite: 1].
* **Average Calories:** 32.90[cite: 1].
* **Average Caffeine:** 35.94[cite: 1].

---

## 📈 Key Visualizations & Insights
1. **Average Calories by Beverage Category:** Visualized using an area chart across categories like Smoothies, Frappuccinos, and Signature drinks[cite: 1].
2. **Starbucks Global Presence:** Represented using a map visualization highlighting store locations[cite: 1].
3. **Beverage Category Distribution:** Displays percentage-wise breakdown of categories via a donut/pie chart[cite: 1].
4. **Caffeine Analysis:** Highlights average caffeine by category alongside the top 5 highest caffeine beverages using bar charts[cite: 1].
5. **Interactive Slicers:** Top filters allow users to dynamically filter data by Protein Range and Beverage Prep[cite: 1].

---

## 🛠️ Tools & Technologies Used
